## 为什么选择源悦TTS

通过对原有工作流程进行深度解析，

我们发现了学生在完成抄写作业时的三个痛点：

**高频切换焦点、视觉负荷过重**导致的**眼干眼涩，**

长时间不健康姿势诱发的**腰颈椎健康风险，**

以及桌面面积过小引起**桌面空间冲突**，进一步 **拖累学习效率。**

源悦TTS软件针对抄写这一精细化场景，

创新性的提出了“抄写内容可听化”的解决方案，

基于文字转语音技术，将电子教材转化为语音，利用听觉通道分担视觉负荷。

基于此场景，源悦TTS推出了诸多[客制化功能](#核心亮点)。

借助源悦TTS软件，

学生可通过全新的抄写工作流高效利用起听觉这一空闲感官，出色的解决这三个核心痛点，

缩短学生完成作业耗时, 使工作流更加高效，

同时通过视听感官联觉加深内容记忆，辅助学生背诵古诗词、长难句。

帮助学生更快速、更健康地完成抄写与背诵作业，使学生的日常生活更加缤纷多彩。

## 核心亮点

### [一键 **从图片导入**](#从图片导入)

- ✅平均 **节省14分钟/1000字**
- ✅AI大模型智能文字识别，**识别正确率相较于传统OCR更高**，在图片模糊/字迹不清时主动**猜测文本内容**
- ✅支持各类**符号、数学公式**等特殊内容
- ✅可指定图片中需要的内容
- ✅可单次导入多张图片

### [**从教科书中指定页码和内容并导入** ](#在线获取教科书内容并导入)

- ✅支持一键 __从Github获取PDF电子书资源__
- ✅支持一键 __从国家中小学智慧教育平台获取PDF电子书资源__
- ✅清晰的教科书分类，便于寻找需要的书籍
- ✅支持指定页码和页面中的内容，避免二次处理
- ✅自动记忆页码偏移量，解决书内页码与PDF页码不符的问题
- ✅自动保存PDF文件，避免重复下载

## Q&A

### 为什么无法正常生成音频

请点击音色列表并选择一个其他的音色。

同时，我们建议您进入 设置-AI设置 选择一个默认音色。

目前，程序偶现音色配置检查功能失效的问题，此问题将很快修复。

### 为什么某个界面缺少图片

可以尝试设置-下载设置中将在线内容源切换到Gitee，然后重启程序。

### 为什么切换配色/字体等自定义选项后没有生效？

重启程序即可。

### 为什么线上导入用不了/加载缓慢

您可以在设置-在线导入设置中将“在线导入模式”修改为“智慧教育平台导入模式”以此获得更高质量的pdf文件并获得更高的下载速度。

或者如果您因为各种原因无法使用此模式，或者需要下载旧版教材的话，可以切回Github仓库模式并尝试在“设置”页面中修改“Github下载加速”项和“下载线程数”。

实在不行就施展一下中国功夫吧。（？

“Github导入模式”下电子书PDF文件来自[Github知名项目Chinatextbook。](https://github.com/TapXWorld/ChinaTextbook/ "点击跳转")。
