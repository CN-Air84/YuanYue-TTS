### Why can't online import be used/loading is slow

[E-book PDF files come from the well-known Github project Chinatextbook.](https://github.com/TapXWorld/ChinaTextbook/ "Click to jump") Therefore, the "online import" function will access the Github server.

If you can connect to the Github server, but the download time is extremely long (also manifested as卡顿 in the "processing" window animation),

then you can change "Github download acceleration" to [ghfast](https://ghfast.top "ghfast") on the "Settings" page.

　

If you cannot connect to the github server,

**In short, please use a VPN.**

　

### Why doesn't the audio playback speed change after enabling audio stretching?

First, you need to install [FFMPEG](https://ffmpeg.org/ "ffmpeg official website"), 

Second, you need to enable "audio stretching" first, then click to generate audio.

　

### Why didn't my changes to xx settings take effect?

Please click "Apply Settings".

Note: There's a bit of messy code, and the "custom font (and font size)" function hasn't been implemented yet.

　


### Why is there a red message box popping up in the lower right corner with an error

Don't hesitate, take a screenshot immediately! Take a screenshot immediately!

Then, find any AI and ask what happened.

If the AI says "You have been blocked by Zhupu Qingyan/EdgeTTS Api", then please ask the AI for solutions.

As long as the AI mentions anything about the program being "imperfect/vulnerable/...",

Please [submit a PR immediately!](/pulls ) It's best to describe in detail what you did before the window popped up and what the program displayed!

Thank you very much!

　


### The "Confirm Clear" window buttons are too small, I can't see them clearly

__That's intentional!__

We have set four "No" and one "Yes" buttons, with completely random positions and extremely small sizes,

forcing users to carefully read the reminder text above,
to avoid accidental deletion of content due to misoperation or too fast operation.

# Program Feature Introduction
## Import from DOCX File
When using this function, users can select a DOCX document in the pop-up window and import it,

without __opening any other software__.



 
In August this year, the development team randomly interviewed some users who have used similar software (90% were students, 10% were clerical staff),

and found that many of them had not used similar free software with this function.

(Note: To "make money", many software have developed this function for VIP, but the VIP cost-performance is very low.)

The team also found that about 40% of users of similar software

wasted time because they used third-party "streamlined" systems without Microsoft Office and could only use Kingsoft WPS with a long cold start time.

(Note: These 40% of users did not know how to manually install Microsoft Office without paying "IQ tax" to rogue software before the interview)

Therefore, we developed this function to save users time and worry.


 

The implementation of this function is not complicated, but it has successfully transformed the traditional****

Find the file to import→Double-click to open a dedicated editor (Microsoft Office Word/Kingsoft WPS, etc.)→(Wait for the software to load)→Select all and copy→Return to the text-to-speech software→Paste

( __Dependent on a dedicated editor__ and excluding the "finding the file" and "moving the mouse" processes, the whole process takes about __fifteen seconds__ (tested on WPS)
If the user's computer is old, they __will wait longer in the second step__)
These __six__ steps are simplified to

Find the file to import→Click to select→Click OK

__Three__ steps (excluding the "finding the file" and "moving the mouse" processes, the whole process takes at most __two seconds__),
__significantly reducing the time users need to operate the software.__

　

## Image Import Function
When using this function,
users can select an image in the pop-up window,
and the program will automatically send it to AI for text recognition and obtain the result.

　

With the popularization of mobile devices, the scenarios where users obtain information have gradually become "visual":

__Paper documents__ photographed for archiving,

__Screenshots__ to save content (such as __online course note screenshots__ , web page fragments),

__Handwritten notes__ photographed for recording, etc.

These images

often contain information that needs to be converted into editable text,

but the __traditional "manual input" method is extremely inefficient__
For example, a picture containing 1000 words of continuous text,
the average person needs __more than 15 minutes__ to input manually,
and it is __easy to make mistakes due to misreading or missing input__ (Note: Data source is AI). Even __professional clerks proficient in touch typing need about 8 minutes__ to complete the input
(Note: The data source is the clerical staff encountered during the interview mentioned in the previous section)

　

At the same time, independent OCR (Optical Character Recognition) tools on the market generally have two types of problems:

__Complex operation__: Need to download a separate tool, upload images, wait for recognition, manually copy the results, then switch to the speech synthesis tool to paste, with multiple links increasing user operation costs;

__Recognition limitations__: Low recognition accuracy for formula symbols and serial number marks from photos or handwritten text, requiring manual proofreading by users, which instead increases workload.

For example:
[Image Example]

The original content is: (1+𝑥)^𝑛=1+𝑛𝑥/1!+(𝑛(𝑛−1) 𝑥^2)/2!+…,

The output is: n(n-)x2
		(1-x)n=1+++=

The original content is very different from the output content,
seriously affecting the normal use of users.

　

Even with AI large language model software like Doubao,
there are problems with cumbersome steps (Note: compared to this function)

　

It is not difficult to find that
most users need a __"one-stop"__ solution:
within the speech synthesis tool
##### Directly complete the whole process of "image→text→speech", while reducing the recognition error rate to infinitely close to 0.
Reduce tool switching and secondary editing costs,
##### Avoid unpredictable losses caused by recognition errors.


　



## Online Access to Textbook Content and Import ##
When using this function, users can one-stop


 
#### Obtain almost all Chinese textbook PDF resources, and specify page numbers and required content.



As students,
the project team has
regarded student groups as the main target users since the beginning of the program development.

　


During the development process, we thought about such a question:
For a student,
what problems are simple and understandable in study life but boring?

At the same time, as a developer, what problems can we easily solve?

　

Our answer is:
#### Turn "copying" homework into "dictation".
Yes, it's that simple.

　

This function transforms the traditional

Take out the mobile phone→Find the textbook→Turn to the corresponding page→Take a photo of the corresponding page with the mobile phone→Transfer the photo to the computer→Use traditional OCR with low accuracy to recognize text→Copy the result→Paste into the input box

( __Dependent on mobile phone__ and excluding the "book flipping, finding the mobile phone and opening the camera app, searching and opening the OCR website" and "moving the mouse" processes,
all operations that require manual operation by the user __take a total of 1-2 minutes__ )
These __eight__ steps 

　

simplified to

Click "Online Import"→Select the corresponding textbook pdf file→Enter the required information

__Three__ steps
( __Not dependent on mobile phone__ and __the whole process takes only 15 seconds at the shortest__)

　

This function effectively utilizes the "auditory" sense, which is idle during copying,

 ### saves the time users need to look up at books while helping users memorize knowledge from books faster, aiding more efficient learning.
