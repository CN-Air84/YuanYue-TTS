登录/注册：

第二步：进行实名认证

根据中国相关法律法规，使用大模型 API 服务通常需要进行实名认证。

登录后，点击右上角的头像或用户中心。

找到“实名认证”或类似的选项。

个人开发者：通常需要输入真实姓名和身份证号，有时需要进行人脸识别。

企业开发者：需要上传企业营业执照等信息。

第三步：创建 API Key

实名认证完成后，即可创建 API Key。

进入管理控制台：登录状态下，点击右上角的 “API Key” 选项，或者在左侧菜单栏找到 “API Key 管理”（有时也称为“开发者控制台”）。

添加 Key：

点击页面上的 “新建 API Key” 或 “创建” 按钮。

系统可能会弹出一个窗口让你输入一个名称（别名）以便于区分（随便填）。

复制并保存：

创建成功后，屏幕上会显示一串以 sk- 开头的字符串（例如 sk-a1b2c3d4...）。

重要提示：这串字符只会显示一次。请务必立即点击“复制”按钮，并将其安全地保存在你的本地代码文件或密码管理器中。
